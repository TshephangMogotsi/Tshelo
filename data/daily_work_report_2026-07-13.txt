4. SMS Detection Scaffold — Built and Verified On-Device (e822391, today)
------------------------------------------------------------------
- New local Expo native module modules/sms-listener: a Kotlin
  BroadcastReceiver forwards incoming SMS ({sender, body}, multipart
  messages stitched) to JS while the app process is alive. RECEIVE_SMS
  contributed via the module manifest and app.json.
- lib/smsWatcher.ts requests the runtime permission and fires an
  immediate local notification when a message matches the test trigger
  "Hello Tshelo"; started from App.tsx once signed in.
- Verified end-to-end today on a physical device (new test unit
  RZCT80CFDZD): real SMS sent -> notification received. The dev client
  APK with the module is EAS build versionCode 3 lineage, installed via
  adb.
- Build gotcha worth remembering: a local Expo module's build.gradle
  MUST define android.defaultConfig.versionName —
  expo-module-gradle-plugin otherwise fails the whole build with a
  misleading error cascade blaming unrelated packages (first EAS build
  failed on this; second succeeded).
- Also in this commit: EAS dev/preview profiles emit APKs, parse-receipt
  edge function reads the "Tshelo_key" secret (was ANTHROPIC_API_KEY),
  project .claude/settings.json, and the 07-05 report file.
