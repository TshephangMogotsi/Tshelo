3. Mobile-Money SMS Parser — New, Provisional (57178b0)
------------------------------------------------------------------
- New lib/smsParser.ts: pure text-in/data-out parser for Orange Money,
  MyZaka, and Smega SMS messages. Detects provider (by sender ID or body
  keywords), direction, amount, counterparty name/phone, reference, and
  balance.
- 127 lines of tests in lib/__tests__/smsParser.test.ts covering the
  provisional regex patterns.
- Explicitly flagged in the commit message as provisional: formats are
  guessed pending real captured SMS messages from each provider. Patterns
  live as data (regexes + fixtures), not logic, so correcting them later
  should only mean editing this one file plus its fixtures.
- Not yet wired into any screen — no importer of smsParser.ts exists
  outside its own test file, so nothing in the app calls it yet
  (auto-detecting contributions from an incoming SMS is presumably the
  intended next step, but that integration hasn't started).
